# To-Do List CLI Application (Python)

A simple console-based to-do list application created as part of the Python Developer Internship Task 2.

## 🔧 Features
- Add a task  
- Remove a task  
- View all tasks  
- Tasks saved permanently using `tasks.txt`  
- Uses lists, file handling, and string manipulation  

## 📁 Project Structure
├── todo.py
├── tasks.txt  (auto-created)
└── README.md

```bash
python todo.py
